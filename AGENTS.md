## Our Website

We are creating an improved version of d21softball.org. We will not be creating a user dashboard. We will register teams via a multi step form for tournaments with a stripe checkout. Backend will be handled with payload cms v4.

## Development server

- Start the app with `pnpm dev`.
- The development server uses port 3000.
- Temporary dev servers started by an agent MUST be terminated before the agent finishes.
- Run `pnpm dev:stop` during cleanup.
- Do not terminate unrelated Node/Vite processes.
